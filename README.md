# 📝 MERN Stack To-Do List App

A simple and responsive To-Do List application built using the **MERN stack** – MongoDB, Express.js, React.js, and Node.js. It allows users to add, update, delete, and mark tasks as complete.

---

## 📌 Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Backend API built with Express and MongoDB
- Frontend with React and Axios for API calls

---

## ⚙️ Tech Stack

- **Frontend:** React.js, Axios, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (via Mongoose)
- **Others:** Nodemon, concurrently (for running both server and client)
